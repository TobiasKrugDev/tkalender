# TKalender
Eine Fullstack Web-App zum Organisieren all Ihrer Termine!

# Demo
[tkalender-demo.de](https://tkalender-demo.de)

Benutzername: Demo User
Passwort: demo

# Features
+ Verwaltung von Terminen, Kontakten, Orten und Kategorien aller Art
+ interaktiver Kalender mit flexiblen Ansichten und Bearbeitungsmöglichkeiten
+ Terminbearbeitung per Drag & Drop
+ Anzeige der gesetzlichen Feiertage
+ Übersichtliches Dashboard für alle Informationen auf einen Blick
+ Blitzschnelle Navigation ohne lange Ladezeiten
+ Farbsystem für Terminkategorien
+ Login-System
+ Google Maps Integration
+ Hinterlegen von Profilbildern für Kontakte
+ Responsive Nutzeroberfläche optimiert für alle Bildschirmgrößen
+ Filtern nach Datum, Name, uvm.
+ Globale Suche
+ Shortcuts für Anrufe und E-Mails
+ uvm.

# Techstack
Frontend: Vue, Quasar, JavaScript, HTML und CSS.
Backend:  PHP und SQL (kein Framework!)
